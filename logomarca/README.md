# Logomarca Atlas Boi

**`atlas-boi-retangular.png`** — sidebar, login, favicon e demais telas.

|---------|-----|

## Sincronizar com o frontend

Após alterar arquivos aqui, rode na raiz do projeto:

```powershell
.\scripts\sync-logomarca.ps1
```

Isso copia os PNGs para `frontend/public/logomarca/`.
